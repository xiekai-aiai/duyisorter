# 算法解读

> 本文从**算法原理 / UI 配置项作用 / 调参直觉**角度讲清 DuySorter 相机板 FPGA 的各类分选算法与公共剔除参数；具体命令字节、CRC 实例、协议文档与代码命令码错位等内容见 [协议解读.md](./协议解读.md)。
>
- 算法真正运行在**相机板 FPGA**（线阵逐行实时处理），上位机只负责配置参数、训练、下发、保存方案。
- 所有算法参数按 **层 level → 识别组 groupId（次×2+前/后视）→ 组内相机板 unit** 三级寻址，逐块板 `com1Write`。
- 算法源码主要在 [material.cpp](../src/rgb/material.cpp)（打包下发）、[arith.cpp](../src/rgb/schemeparams/arith.cpp)（UI）、[paramsprofile.cpp](../src/params/paramsprofile.cpp)（方案读写）、[globalflow.cpp](../src/globalflow.cpp)（下发编排/延迟）。

## 0. 总体处理流水线与公共概念

### 0.1 从像素到喷阀

```
RGB/红外原始像素（线阵逐行扫描）
  → 各算法阈值/模型判定            灰度/色差/复合/形选/大小/选尖/智能…
  → 二值缺陷掩膜（坏=255）
  → 切边（丢弃物料进出视野的边缘行）
  → 形态学：腐蚀去噪 → 膨胀补区
  → 传染（沿运动方向把坏信号延续若干行）
  → 区域/连通域统计（行×列斑点数、整颗形状/尺寸）
  → 坏点门限（坏点太少不喷）
  → 前后视合并（与/或）、正反选
  → 喷阀位图：基础/精选吹气模式 + 联动扩宽
  → 延迟对齐后开阀
```

各"识别算法"决定**哪里是坏料**，辅助参数（剔除参数页）决定**坏信号怎么整理、怎么合并、最终喷多宽**。

### 0.2 线阵相机几何：行、列、斑点

- 相机是**线阵**：一行横跨传送带 = **列**（T3-1024 为 1024 列）；物料随传送带运动的方向 = **行**。
- 多数像素窗类算法用「**行数 × 列数**」划出一个判定小窗，窗内坏像素个数 = **斑点数 nPercent**；斑点数达到门限才算命中。
- 列数随行数自动：`nColumn = nRow × rowColumnRelation`（K/T2/T3-2048 为 2，T3-1024/D2/P5 为 1）。
- 斑点数上限 = 行×列，如 T3-1024 行 32 → 32×32 = 1024。

### 0.3 阈值百分比 ↔ 0~255 换算

| 算法族 | 界面档 | 内部量 | 换算系数 |
|---|---|---|---|
| 灰度 / 复合 / 长短 / 保留 / 形选 | 0.1% | 0~1000 | **×0.255** |
| 色差（两通道比值） | 0.01% | 0~10000 | **×0.0255** |
| 大小 | 整数 | 0~65535（16 位） | **不换算**，直接发原始尺寸 |

255 是 ADC 满量程，但窗口检测的是**一整段区间**而非单个等于 255 的点。

**单端窗口与选向**：

- 选暗 / 选短 / 选小 → 低端窗口 `[0, 阈值]`；
- 选亮 / 选长 / 选大 / 复合 → 高端窗口 `[阈值, 满量程]`；
- 灰度杂质支持自定义双侧区间（下阈~上阈）。

### 0.4 四种参数组合模式 `nMatAssembleMode`

| 值 | 含义 |
|---|---|
| 1 PARAMS_ALL_SAME | 全部相同（所有组共用 group 0） |
| 2 PARAMS_FRONT_REAR_SAME | 前后视相同（同一次内前/后视共用前视） |
| 3 PARAMS_FIRST_SECOND_SAME | 前视相同、后视相同 |
| 4 PARAMS_ALL_SEPARATE | 全部独立（每组一份参数） |

改一组参数后，`materialResetGroupAssemble()` 按该模式决定联动复制到哪些组再逐板下发。

## 一、像素窗口类算法（在 行×列 窗内数坏像素）

### 1.1 灰度杂质 A/B（单色1 / 单色2，0x4001~0x4004）

**原理**：最基础的单通道亮度判定。每个算法各有阈值包（-1）和区域包（-2）：

- **阈值包**：对 R/G/B 三通道分别给「红低/红高、绿低/绿高、蓝低/蓝高」，像素任一通道路在区间内即记为坏点。Byte7 是 RGB 三通道选择位（1=R、2=G、4=B，可位或）。
- **区域包**：行数、列数、斑点数（窗内坏点门限）、亮度下限。

UI「选暗」只生成单侧区间 `[0, 上阈]`，「选亮」生成 `[下阈, 255]`；底层命令支持任意上下阈双侧区间。单色1/单色2 是两份独立判据，命中为或。

**调参**：上阈调低→更暗才算坏（选暗更严）；斑点数调大→要求坏点更集中，抗噪强但漏小缺陷。

### 1.2 色差杂质 A/B（色差1 / 色差2，0x4005~0x4008）

**原理：看两通道的比值（颜色偏向），而非绝对亮度。** 光照变强时 R/G/B 近似同比例增大，取比值后光照影响被抵消，因此比灰度更稳：

```
色差特征 = 分子通道 / 分母通道     分子、分母在 Byte10 高/低 4 位指定（1=R,2=G,4=B）
```

Byte10 是"**通道选择器**"，不是颜色值；8 位 RGB 原始值留在 FPGA 内部做除法。比值 ≈1 表示两通道均衡，偏离 1 表示偏色。阈值精度为 0.01% 档（×0.0255）。UI 上 6 个按钮 = 3 对通道组合 × 2 偏离方向。区域包列数 = 行数 × rowColumnRelation，斑点数上限 = 行×列。

**调参**：适合按"颜色偏向"区分（如发黄、发红），光照不稳的产线优先用色差而非纯灰度。

### 1.3 复合 / 差分杂质（0x400A 阈值 / 0x400B 区域）

**原理：单个颜色通道的强信号检测**，固定高端窗口 `[下阈, 255]`，精度 0.1% 档（下阈字节 = 255 − 精度×0.255）。

红/绿/蓝是**三选一互斥单选**（`struCross.nColor = 1<<index`），**不是"红且绿且蓝"的与条件**，一个复合算法一次只监看一个通道。要多通道把关时，应同时使能多个独立算法，算法之间是**或关系**。255 表示"上不封顶"，不是只挑饱和点。

**调参**：用于某种颜色特别突出的杂质；下阈越高越只挑颜色很纯/很强的目标。

### 1.4 保留参数（病斑分选 / 反选保护，0x14 / 0x15 / 0x4022）

**作用：主算法命中后做二次复核，避免把"只带一小块病斑的好料"整颗吹掉。**

- 保留1 = 高级色差复核（两通道比值，命令 0x14）；保留2 = 高级灰度复核（单通道亮度，命令 0x15）；Byte9 固定为 3，标识该判据挂在色差杂质 A 上。
- 保留比例经命令 0x4022 下发，换算 `nRsvArea = nRow × 16 × (100 − nPercent) / 100`。
- 灵敏度为 0.1% 档（×0.255），比主色差的 0.01% 档粗。
- 灰度/色差算法的保留页**不显示病斑比例框**（仅细杆/茶叶类可见）。

**调参**：反选（保留好料）场景必备；复核越宽松，带病斑好料越不容易被误剔，但真正的坏料也更可能漏网。

## 二、整颗连通域类算法

与上面"窗内数坏点"不同，这一类先把坏像素连成**一整颗连通物料区域**，再算整颗的形状/长度/尺寸。

### 2.1 形选：选圆 / 选长（0x22，长短 0x3F）

**原理**：对整颗连通区域输出一个 0~255 的形状特征量（偏圆↔偏长落到两端），再用**单端窗口**选一端：

- `nMode=0` 选圆：高端窗 `[255−精度×0.255, 255]`；
- `nMode=1` 选长：低端窗 `[0, 精度×0.255]`。

**为什么只有"参数下限"没有上限**：`nAreaLimit` 是**面积下限**（16 位），用来滤掉小于该像素数的碎渣噪声；尺寸分选由独立的大小算法负责，故不需要面积上限。形选与长短**总是成对下发**（共用 struShape、共用使能 D5）。

### 2.2 长短：选短 / 选长（0x3F，协议文档 0x001E）

**原理**：量整颗物料沿运动方向的整体长度 L：

- `nLengthMode=0` 选短（L≤上界剔除）；`=1` 选长（L≥下界剔除）。
- 这里的"精度"是**长度阈值占满量程的百分比**，不是测量误差：

```
满量程 = 255 × sensorPixelsQuo     T3/2564 quo=2 → 510；其余 quo=1 → 255
选短: 上界 = 精度 × quo × 0.255
选长: 下界 = 255×quo+1 − 精度 × quo × 0.255
```

同一个百分比在不同分辨率传感器上自动对应不同像素阈值；协议字段为 10 位（0~1023）。所以"最长不是 255 像素"——T3/2564 满量程是 510。

### 2.3 大小1 / 大小2（0x4009 / 0x4010；旧 2566 为 0x16）

**原理**：判整颗物料的**个头（尺寸/面积量）**，与圆长无关：

- `nMode=0` 选小（尺寸 ≤ 阈值剔除），`=1` 选大（尺寸 ≥ 阈值剔除）。
- **精度是整数 16 位（新传感器 0~65535，旧 2566 为 0~4095）**，不是百分比、不乘 0.255，直接发原始尺寸值——尺寸量级可达上万像素。
- 「参数下限」nValueLimit 同为整数，是最小有效目标尺寸，用来滤碎渣；没有上限，超大块靠选大模式处理。

**分工记忆**：形选管"圆还是长"、长短管"有多长"、大小管"个头多大"，互不替代。

### 2.4 选尖1 / 选尖2 / 花生选芽（0x400C / 0x400D）

**为什么有两个按钮**：针对花生芽尖、芽体两种形态，提供**两套相互独立、可同时勾选**的「行/列区域 + 面积 + 斑点门限」判据（各自 struBud[0]/[1]），命中为**或关系**——一个抓尖、一个抓体，兼顾漏检率与误喷率。不是同一参数的上下限。

新码一包含行/列/面积/斑点门限，面积字段取反 `255 − nArea×2.55`；旧 2566 拆成 MISC（0x1E/0x20）+ AREA（0x1F/0x21）两包。

## 三、学习类算法

### 3.1 智能1：相机板 FPGA 多特征线性分类器（0x400E、0x71~0x7A）

**定位**：跑在**相机板 FPGA** 上的加权线性分类器，参数是一组权重系数，靠现场拍好料/坏料样本 +「智能分析」自动拟合。**不要和 AI 板（ARITH_PISTACHIO，UDP 9193 下发 .bin 神经网络）混淆**——后者是外置 AI 板上的深度学习模型。

多分类模式（nIntelMode=1，现行默认）判定式：

```
score = c + wR·R + wG·G + wB·B
          + wRG·(R·G) + wRB·(R·B) + wGB·(G·B)
          + wRR·R² + wGG·G² + wBB·B²
score 越界即判坏料
```

- **低维（nAIMode=1，默认）**：只拟合前 6 项（3 原色 + 3 交叉项 RG/RB/GB）。
- **高维（nAIMode=0）**：再加 3 个平方项 RR/GG/BB。
- **颜色空间 nColorSpace**：0=RGB、1=HSV，决定特征代入哪套分量。
- 权重为 31 位有符号定点数，逐特征用命令 0x72~0x7A 下发，常数项 0x71 随界面「灵敏度 nSens」整体缩放（调松紧无需重训）。
- 训练时权重归一化为 `2·nQuo/(nMax−nMin)·1e7`。

**单独设置 / 相同设置（按"次"独立）**：智能主页按钮翻转 `nMatAssembleModeIntel`（key 3-5-1，0 相同 / 1 独立，默认独立）。相同设置时同一样本属性同步到所有识别组；单独设置时只写当前前/后视组，可逐组采样、逐组训练。要真正按"次"独立，还需总组合模式选 **PARAMS_ALL_SEPARATE(4)**，否则训练后参数仍会按四模式联动复制成相同。

### 3.2 智能1「设置」高级参数页

| 区块 | 配置项 | 作用 |
|---|---|---|
| 导入\导出图像 | 导入/导出 | U 盘/SD 卡 ↔ /tmp 搬运训练样本 PNG，**不发串口** |
| 高级参数 | 颜色空间1/2 | 0=RGB，1=HSV（nColorSpace，随 0x400E Byte11 下发，key 3-33） |
| 高级参数 | 分类模式 高维/低维 | nAIMode，决定 9 特征还是 6 特征（key 3-34，默认低维） |
| 高级参数 | 采样阈值 | nIntelSampBurst，0~255，自动取样的"触发像元个数" |
| 拍照算法 | 高速 / 低速 | nIntelSampType，1=USB（默认）/0=UART，只决定取样回传通道 |
| 其它 | 自动复制 A→B | 把智能 A 常数+9 权重整体复制给智能 B |

> 分组标题界面显示"腐蚀圈数"是翻译残留错误，源码键为 advanced_parameters，实为"高级参数"。

**采样阈值（触发像元个数）详解**：线阵相机逐行扫描，不可能每行都上传一帧。FPGA 每行统计"与背景有差异的像元个数"，`异常像元数 ≥ 采样阈值` 才认为来了一颗料、触发抓拍一帧：

- 调小→灵敏不漏料，但碎渣/光照波动易空拍；调大→滤噪但小料可能漏采；0=最灵敏（默认）。
- 它**不是色选判定阈值**，只用于训练取样阶段。
- 命令 0x36：Byte8=去背景、**Byte9=0 主动抓一帧（智能分析页拍摄，随后立即发 0x03 取图）/ 0x01 硬件自动触发（主页拍摄实时监看）**、Byte10/11=阈值高/低字节。Byte9 由代码按场景硬编码，界面只配阈值数值与高/低速。

## 四、剔除后处理（辅助参数页 PageTick）

页面类 [PageTick](../src/rgb/schemeparams/tick.cpp)，顶部 tabBar 在多个**剔除组**（第一次/第二次、前/后视）间切换，一套控件编辑当前组 `struGroupTick[level][tickGroup]`，方案 key 前缀 `3-15-<level>-<group>-<field>`。

### 4.1 吹气算法：基础 / 精选（nEjwidth，接口板 0x04）

| UI | 值 | 含义 |
|---|---|---|
| 基础 | 1 | 固定吹气宽度 |
| 精选 | 4 | 自适应/扩展吹气宽度（按目标大小自适应喷气范围，默认） |

按剔除组逐组下发到接口板。新建方案默认 4。key field=4。

### 4.2 传染（nImpured / nImpuredFlag，CMD_UNIT_INFECT）

- **含义**：某位置一旦判坏，沿**物料运动方向（行方向）**把坏信号延续 `nImpured` 行。相当于时间/行方向上的延长，保证高速运动、条状/断续缺陷也能完整触发喷阀，而不只是一瞬间。
- 与（空间）膨胀的区别：膨胀是在二维掩膜上向四周扩像素；传染是沿扫描/运动方向延续坏信号若干行。
- 「默认」复选框（nImpuredFlag）勾选后自动填最大行数 `maxRowNumber` 并锁定手填；不勾选可自定义行数（彩色米机上限 7，其它 62）。
- 反选时强制要求开传染（checkReverseSort 校验）。色选、形选各一份（nImpured / nShapeImpured）。
- 传染行数计入延迟：`nEjectImpureDelay = delayPerRow × nImpured`。

### 4.3 腐蚀圈数 / 膨胀圈数（nCorrupted / nExpanded，CMD_UNIT_INFECT 同包）

对**二值缺陷掩膜**做形态学（PC 预览等价实现见 [myvideo.cpp](../src/myvideo.cpp) 的 erosion/dilation，3×3 八邻域）：

- **腐蚀**：邻域 9 点全为坏才保留 → **抹掉孤立噪点/灰尘/边缘毛刺**。
- **膨胀**：邻域内只要有一个坏点就置坏 → **把坏区无条件向外"染"一圈**。注意是邻域 OR 直接标记，**不会对邻居重新做颜色判定**；1 圈外扩约 1 像素，N 圈迭代外扩约 N 像素（细线宽度约变为 原宽+2N）。

典型用法：先腐蚀去噪、再膨胀补回有效区（开运算思想）。作用：

1. 连接反光导致的破碎/断裂病斑；
2. 扩大喷气覆盖面，保证整颗打掉、补偿物料错位；
3. 兜住边缘漏检。

**代价**：膨胀过大→把紧邻的好料带进吹气区（误喷、带出比升高）；圈数还增加处理延迟（边缘切除延迟 = `delayPerRow ×(nEdgeCut + nCorrupted×3 + nExpanded)`，腐蚀一圈按 3 行计）。范围：普通 0~32，彩色米机限 3~4（米粒小易糊到邻粒）。

### 4.4 坏点（nBadNum，CMD_UNIT_BAD_NUM=0x17；协议文档 0x0014）

最终一道"**坏点太少就不喷**"的数量门限：一个通道/喷嘴区域内坏点数 `≤ nBadNum` 视为噪点不喷，超过才喷。范围 0~255，默认 1（单个孤立坏点不喷）。

与各算法"斑点数 nPercent"的区别：斑点数是**单个算法区域包内**的命中条件；坏点是**剔除组公共**、作用在最终通道喷阀结果上的兜底门限。key field=6。

### 4.5 切边 / 边缘补偿 / 平衡病斑（CMD_UNIT_EDGE_CUT=0x19；协议文档 0x0016）

- **切边 nEdgeCut（field=5，UI 0~3，协议 0~8）**：物料刚进入/刚离开线阵视野时像元不完整，易产生明暗突变黑边假缺陷。切边把判定区边缘 N 圈/行丢弃不参与统计，避免头尾误喷。
- **边缘补偿 nEdgeRevise（field=10）**：勾选后让固件对边缘做补偿而非简单丢弃。
- **平衡病斑 nEnableBalance（field=11）**：主要用于茶叶/智能算法的病斑面积平衡；开启后智能"斑点%"改读 nBadNum，配合 nGoodNum/nMatWidth/nMatArea 一起工作。

### 4.6 联动（nhuffWidth，CMD_UNIT_HUFF_WIDTH=0x66，仅杂粮 CF 显示）

- UI 译"联动"，代码注释实为"**吹气宽度**"，范围 0~31，默认 0。
- 某通道判喷后，固件按此值把**最终喷阀信号向相邻通道/喷嘴扩展**，容忍物料位置偏移、缺陷跨喷嘴边界、单嘴气流覆盖不足。0=不额外联动。
- 与「基础/精选」的区别：基础/精选选的是喷气宽度**算法模式**（接口板 0x04）；联动是在最终喷阀位图上的**额外扩展量**（相机板 0x66）。与膨胀的区别：膨胀扩的是坏像素掩膜，联动扩的是最终喷阀信号，都不重新判颜色。key field=51。

### 4.7 前后逻辑 / 正反选

- **前后逻辑 nFrontRearMode（色选）/ nShapeLogicMode（形选）**：前视与后视判定结果如何合并，0=**或**（任一视角判杂即剔，选出率高），1=**与**（两视角都判杂才剔，带出率低）。
- **正反选 nReverseSort（色选）/ nShapeSortMode（形选）**：0=正选（按杂质特征剔除坏料），1=反选（按保留目标反向工作，留下好料）。反选时强制要求开传染。

### 4.8 调参直觉速查

| 参数调大 | 好处 | 风险 |
|---|---|---|
| 腐蚀 | 去噪、去毛刺 | 小缺陷被吃掉、漏检 |
| 膨胀 | 连破碎缺陷、覆盖整颗 | 误喷相邻好料、增加延迟 |
| 传染行数 | 高速/条状缺陷不漏喷 | 喷气延续过长带出好料 |
| 坏点 | 抗噪 | 小缺陷漏喷 |
| 切边 | 消除头尾假缺陷 | 头尾真缺陷漏检 |
| 联动 | 偏移/跨嘴目标吹得掉 | 带出好料增多 |
| 前/后视 或→与 | 带出率低 | 只被一个视角看到的缺陷漏检 |

## 五、全链路时序：为什么这些参数会影响延迟

形态学（腐蚀/膨胀）、传染、切边都要缓存相邻若干行后才能判定，因此代码按各行数统一折算成时间，保证"判定时刻"与"物料到达喷嘴时刻"对齐：

```
边缘切除延迟 = delayPerRow × (nEdgeCut + nCorrupted×3 + nExpanded)
传染延迟     = delayPerRow × nImpured
```

最终吹气延迟取色选/形选各路径的较大值（[globalflow.cpp](../src/globalflow.cpp) getDelayEdge / getDelayImpure / resetEjectTime），再叠加吹气时间、消磁、截断等喷阀物理量。调这些形态参数后，软件会重算延迟，无需手动改吹气时间。

## 六、背景设置与前景分割（PageBackground）

> 时序上它是整条流水线的**第 0 步**：先把"物料像素"从"背景衬板"里分割出来，灰度/色差等算法才只在物料区域上判废。背景设错，后面所有算法一起错。

### 6.1 页面构成（代码创建，非 .ui）

- **背景波形曲线 MyCurve**：实时显示选中相机板**一行 1024 像元的 R/G/B 亮度波形**，是看背景平不平、干不干净、灯饱不饱和的"示波器"；切板号只切换波形，不影响灯下发目标。
- 参数区：

| UI 显示 | 真实含义（注意误译） | 字段 | 范围 |
|---|---|---|---|
| 颜色 ◀▶ | 衬板颜色 黑0/红1/绿2/蓝4/白7（RGB 位掩码，白=7） | nBackgroundColor | — |
| **背景亮度** | **分割阈值**（不是灯亮度！） | nBackgroundColorValue | 0~255 |
| **背景角度 %** | **背景色通道占比门限**（不是物理角度！） | nBackgroundColorPer | 0~100% |
| 自动 + 红/绿/蓝 | 背景自适应使能 + 三通道允许漂移幅度 | nAutoBgEnable / nAutoBgRange[3] | 0~255 |
| 前背景灯 R/G/B | 前视背景灯带三路 PWM | nLampLight[12/13/14] | 0~4095 |
| 后背景灯 R/G/B | 后视背景灯带三路 PWM | nLampLight[30/31/32] | 0~4095 |

> "背景亮度/背景角度"是 zh-cn.ts 中 `threshold`、`background_proportion` 的 unfinished 误译。

### 6.2 分割原理：阈值 + 占比两个互补条件

- **黑/白衬板（消色）**：只比总亮度。像素比白背景暗过阈值、或比黑背景亮过阈值 → 物料。固件用三通道和（0~765），故黑白背景下发时阈值 **×3 拆 16 位**。
- **红/绿/蓝彩色衬板**：单看亮度会被同色物料骗过，再加**通道占比**条件，二者是 AND：

```
某通道占比 = 该通道 / (R+G+B) × 100%        // 绿衬板即 G/(R+G+B)
判定物料 = 该通道偏离背景 > 阈值(强度条件)
           且 通道占比低于门限(色度条件)
```

比值对光照强度不敏感（与色差算法两通道比值消光照同理）：灯亮时物料与背景的 G 绝对值可能只差 30，但绿占比可从 65% 掉到 40%，照样分开。50% 对应下发 Byte11 = 255×50/100 = 128。

调参方向：

- **阈值调大 / 占比调大** → 分割更严格，抗脏衬板、抗光照不均，但物料边缘被吃、近背景色物料漏检；
- **阈值调小 / 占比调小** → 分割完整，但灰尘、阴影、偏色反光会造成假前景，后续误喷增多。

### 6.3 「自动」按钮：抓一行波形反算阈值（一键标定）

对每块板发 CMD_UNIT_IMAGE(0x03) 抓一行原始 RGB，只统计该板通道区间，自动给出建议值（setBkgValueAuto）：

- 黑背景：取背景亮度**最大值 +30**；白背景：取**最小值 −30**；
- 彩色：亮度最小 −30，占比取**最小 −5 个百分点**（先剔除偏差 >30 的异常像元）；
- ±30/±5 是给背景波动留的安全裕量：门限必须站在"背景"这一侧。

### 6.4 「自动」勾选：运行中背景自适应

勾选后 FPGA 持续跟踪粉尘堆积、灯管老化、温升造成的背景电平缓漂，自动平移分割门限；红/绿/蓝三个值是各通道**允许跟随的漂移带宽（ADC 码）**：

```
实测背景在 [初始背景 ± range] 内 → 正常漂移，门限跟随
超出 ± range                    → 不跟随（防止把突变/物料学进背景）
```

50/50/50 ≈ 每通道满量程 20% 带宽。range 过大可能把同色物料当背景学走导致越跑越漏；过小则衬板稍脏就跟不动。**必须在停机、衬板干净时勾选**（下料中开启会被拦截），让 FPGA 先学到正确基线。

### 6.5 前/后背景灯：真正的物理照明

- **粒度**：只到「前视/后视」×「R/G/B」共 **6 个全局值**（struGroupCtrl[0] 一份），**不按相机板/溜槽独立**；同视所有板共用一条整条贯穿的背景灯带。
- 每值 0~4095 = 12 位 PWM 恒流驱动，280 约为 6.8%（较暗档）。走 **com2 控制板** CMD_CTRL_SET_LIGHT/CTRL_LED，每块智能恒流源底板最多 6 路灯：

```
板号 = 灯索引/6，口号 = 灯索引%6，亮度拆高(/256)低(%256)两字节
```

- 索引是写死的硬件接线表：

| 灯路 | 索引 | 板号 | 口号 |
|---|---|---|---|
| 前背景 R/G/B | 12/13/14 | 板2 | 0/1/2 |
| 后背景 R/G/B | 30/31/32 | 板5 | 0/1/2 |

8 块恒流源板（×6 口 = 48 路）按灯架实际位置编排角色：板0 前物料、板1 后背景、**板2 前背景**、板3 后物料、板4~7 为第二排重复（板5 后背景…），故同为背景灯前视落在板2、后视落在板5，板号不连续。单色米机另有单路灯索引（前8/后2，辅配11/5，R2 机型5/2），是另一套接线表。

### 6.6 调试顺序与下发/保存

1. **先调 6 路灯**：看波形让背景基线饱满但不饱和（不到 255）；
2. **再定阈值/占比**：用「自动」标定或按波形手动卡分割线；灯一改，阈值要重新标定；
3. 运行中脏污漂移交给「自动」自适应带宽。

- 相机板 com1：背景颜色/阈值/比例 `CMD_UNIT_BG_COLOR=0x12`；自适应使能/RGB 幅度 `CMD_UNIT_BG_ADJUST=0x86`。
- 控制板 com2：灯亮度 CMD_CTRL_SET_LIGHT；背景灯角度 CMD_CTRL_BACKGROUND（当前页未暴露）。
- 寻址：背景参数按「层 × 前视(0)/后视(1)」存储（getBackgroundGroupID = nUnit%2，同视各板共用），自适应下发时枚举同视所有板。
- 方案 key：3-8-层-组(颜色) / 3-9(阈值) / 3-10(比例) / 3-51-层-板(自适应使能) / 3-52-层-板-通道(RGB 幅度) / 3-16-控制板-5/-6(背景灯角度)；灯亮度随控制板参数保存。
