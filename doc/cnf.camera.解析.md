# cnf.camera 相机参数文件解析

## 1. 文件基本信息

| 项 | 内容 |
|---|---|
| 文件路径 | `/opt/app/userdata/cnf/cnf.camera`（`CNF_CAMERA`，globalparams.h L536） |
| 备份文件 | `/opt/app/userdata/cnf/cnf.camera_2`（`CNF_CAMERA_B`，globalparams.h L537） |
| 格式 | INI，仅 `[General]` 段，键值平铺 |
| 读取函数 | `GlobalFlow::getCameraSetting(const QString&)`，paramscamera.cpp L5-150 |
| 保存函数 | `GlobalFlow::saveCameraSetting(const QString&)`，paramscamera.cpp L153 起 |
| 外层封装 | `getCamera()`（L446，开机 initAll 调用）/ `saveCamera()`（L568，工厂设置、机型设置调用） |
| 读取方式 | `QSettings(fileName, QSettings::IniFormat)`，精确匹配键名，无正则、无通配 |
| 缺键处理 | `setting.value(key, 当前值)`，键不存在时保留 `getCamera()` 预置的默认值 |
| 返回值 | `setting.status() == QSettings::NoError` 返回 true，否则 false（getCamera 据此做主/备文件切换） |

## 2. 键名结构

```
2-0-<层号>-<项目号>-<单元号>[-<喷嘴号>]
```

| 段 | 含义 |
|---|---|
| `2` | 相机参数域（固定值） |
| `0` | 彩色相机（预留给其他相机类型） |
| 层号 | 0 ~ MAX_LEVEL-1（本机单层，恒为 0） |
| 项目号 | 参数 ID，见下表 3、表 4 |
| 单元号 | 相机板/识别单元地址，0 ~ MAX_UNIT-1（本机为 0、1 两台） |
| 喷嘴号 | 仅项目号 2、3 需要，0 ~ nEjectorsPerChute-1（本机 0~63） |

玉米机型的两段象元范围键结构特殊，为 `2-0-0-<0|1>-<层>-<单元>-<段号>`。

## 3. 按层/单元读取的参数（表 1）

结构体：`struLevelCameraInfo struLevelCamera[MAX_LEVEL]`（globalparams.h L1089-1113），每层按单元号 `j` 分别存储。

| 项目号 | 键模板 | 结构体字段 | 含义 / 作用 | 默认值 | 本机配置文件示例 |
|---|---|---|---|---|---|
| 0 | `2-0-<层>-0-<单元>` | `nChannelBegin[单元]` | 有效象元起点（该相机参与识别的起始像素列） | 100 | 单元0=120，单元1=86 |
| 1 | `2-0-<层>-1-<单元>` | `nChannelEnd[单元]` | 有效象元终点 | 900 | 单元0=953，单元1=915 |
| 2 | `2-0-<层>-2-<单元>-<喷嘴>` | `nChannelEjectorBegin[单元][喷嘴]` | 单个喷嘴的象元起点（FPGA 像素→喷嘴映射） | 由 100~900 按喷嘴数均分 | 单元0 喷嘴0=120 |
| 3 | `2-0-<层>-3-<单元>-<喷嘴>` | `nChannelEjectorEnd[单元][喷嘴]` | 单个喷嘴的象元终点，`end[k]=begin[k+1]-1` | 同上 | 单元0 喷嘴0=132 |
| 4 / 5 / 6 | `2-0-<层>-4|5|6-<单元>` | `nBiasingRed/Green/Blue[单元]` | ADC 偏置（R/G/B），调整暗电平 | D2 传感器 128，其余 0 | 未写（=0） |
| 7 / 8 / 9 | `2-0-<层>-7|8|9-<单元>` | `nAnaGainRed/Green/Blue[单元]` | 模拟增益 R/G/B | 0 | 未写（=0） |
| 10 / 11 / 12 | `2-0-<层>-10|11|12-<单元>` | `nDigiGainUpperRed/Green/Blue[单元]` | 数字增益高 4 位 R/G/B | 3 | 单元0/1 均为 0/0/1 |
| 13 / 14 / 15 | `2-0-<层>-13|14|15-<单元>` | `nDigiGainLowRed/Green/Blue[单元]` | 数字增益低 4 位 R/G/B | 0 | 单元0=26/0/20，单元1=39/20/30 |
| 25 | `2-0-<层>-25-<单元>` | `nEjectorBegin[单元]` | 参与象元划分的喷嘴起始编号 | 0 | 未写（=0） |

| 29 | `2-0-<层>-29-<单元>` | `nContraPosBias[单元]` | 三次反选对位偏置 | 0 | 未写（=0） |
| 30 | `2-0-<层>-30-<单元>` | `nContraPosCorrect[单元]` | 三次反选对位偏置修正 | 0 | 未写（=0） |

说明：
- 项目号 16 ~ 24、27、28 在代码中未被读取，属保留空号。
- 项目号 2/3 的取值个数取决于喷嘴数量（`nEjectorsPerChute`），数组上限为 `MAX_EJECTOR`=120。
- `nChannelEjectorBegin/End` 由 `calDivChannelParams()`（paramscamera.cpp L597-627）用 `(nChannelBegin, nChannelEnd]` 按喷嘴均分，并叠加 `struGsh.fPixelCompensate[]` 像素补偿；首尾相接、不重叠。

## 5. 参数作用归类

| 类别 | 参数 | 作用 |
|---|---|---|
| 视场几何 | 项目 0/1、2/3、玉米 0/1、2-10/2-11 | 决定每台相机实际处理哪些像素列，以及每个喷嘴负责哪一段像素（FPGA 像素→喷嘴映射） |
| 喷嘴范围 | 项目 25/26 | 限定参与象元划分的喷嘴编号区间 |
| 图像质量 | 项目 4~15（偏置、模拟增益、数字增益高低位） | 调整图像亮度、颜色通道增益，配合白参考做白平衡 |
| 白平衡 | 2-3/4/5、2-17/18/19 | 光源标定的 RGB 参考值 |
| 传感器/光学 | 2-6 ~ 2-9、2-14 | 决定行频、分辨率、是否需要镜头畸变校正 |
| 曝光 | 2-12/2-13 | 前/后视曝光档位 |
| PMT | 2-15/2-16 | 黄曲霉毒素检测帧起点 |
| 对位 | 项目 29/30 | 三次反选时的对位偏差与修正 |

## 6. 几个容易误解的点

1. **文件是增量快照**：`saveCameraSetting()` 只写与 `_t_struCnfc`（上次加载/保存的内存快照）不同的键。因此文件中没出现的键，代表"值未变化"，运行时取代码默认值（或预置值），不是 0。
2. **主备文件**：`getCamera()` 先判断 `struCnfs.value`。正常状态读 `cnf.camera`，读取成功后覆盖 `cnf.camera_2`；若 `struCnfs.value == CAMER_FILE_ERROR`（上次保存失败），改读 `cnf.camera_2` 并回写主文件。
3. **坐标基准**：项目 0/1/2/3 的数值是传感器一行像素的列号（1024 传感器为 0~1023），不是喷嘴序号，也不是从 0 开始重新计数的相对值。
4. **缺键不会报错**：`QSettings::value()` 缺键返回传入的默认值；只有键存在但值非法（空串/非数字）时，`toInt()` 才会得到 0。
5. **单元号与 UI Tab 的关系**：单元号是相机板地址，识别组是参数逻辑分组；单层双组机型一般单元 0/1 对应前视/后视两台彩色相机。
