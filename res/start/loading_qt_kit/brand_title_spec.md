# brand_title_spec.md — 品牌区版式规范

> 品牌区文字由 Qt 代码绘制，**不切图、不烧进背景**。
> 画布 1024×768，安全区四周 32px；下列坐标为基线（baseline）坐标。

## 1. 厂商 LOGO

| 项 | 值 |
|---|---|
| 文件 | `brand_logo.png`（160×48，PNG-24 + 真透明 alpha） |
| 贴放坐标 | (32, 684)，1:1 不缩放 |
| 内容框 | 约 (38, 686) - (82, 730)，即约 44×44 的几何标记（含柔光） |
| 透明留白 | 四周 ≥ 8px，边缘 alpha=0，无白边/黑边 |
| 配色 | 六边形描边 `#67E8F9`、内部点阵 `#CFFAFE` |

**占位说明**：该标记为中性几何占位（六边形 + 分选点阵），不含任何厂商文字，
可直接替换为真实 LOGO（同尺寸、透明留白一致即可，无需改动坐标）。

**备选真实素材**：`brand_logo_vendor_alpha.png` 取自项目内
`res/png/Vendor_Alpha.png`（ALPHA SORTING TECHNOLOGY）：白底转真透明、
统一单色化为 `#67E8F9`、高度归一到 30px、四周留白 10px。
若采用，请确认品牌授权与深色底下的可读性。

## 4. 绘制注意

- 文字颜色为不透明值，不要加半透明阴影溢出画布边缘（最右下像素距边界 32px）。
- 字体文件需随 `qrc` 打包（RK3568 系统镜像通常不含 Noto Sans SC）。
- 品牌区与进度条区域（y=603~611）垂直间隔 ≥ 65px，互不遮挡。
