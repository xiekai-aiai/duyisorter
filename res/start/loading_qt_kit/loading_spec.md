# loading_spec.md — RK3568 / Qt 5.15 启动画面分层规范

> 参考动图：`~/Desktop/new_res/loading_new.gif`（1440×1080 / 100 帧 / 10s）
> 本套素材按 **1024×768（4:3）** 重新构图，保留深蓝 HUD 氛围、青色主色、
> 细描边与克制辉光；**阶段文字与进度条全部由 Qt 代码绘制，不烧进背景**。
> **v2**：取消静态底板中的**中央菱形**与**全部网格纹**
> （全屏 32px 细网格 + 底部平直地网），底板改为纯净渐变 + HUD 线条；
> 动态光环层环心的呼吸光点也一并移除。
> **v3**：光环圆心重新加入 **「AI」字符标识**（粗体冰白 + 左右细方括号，

> **只烧在静态底板，动态光环层与 PNG 序列仍是零文字**；
> 同时以独立透明贴层 `ai_mark.png` 交付，Qt 端可单独着色/隐藏。

> 旋转虚线环/扫描亮弧/刻度点、版式坐标、四态进度条与品牌区均不变。

## 1. 落地方式（重要）

- 全部资源通过 `qrc` 编译进二进制，运行时零外部依赖。
- **Qt 5.15 的 `QMovie` 不支持 APNG**。推荐用 `loading_ring_seq/ring_00..39.png`
  配 `QTimer(75ms)` 逐帧 `QPixmap` 绘制；`loading_ring_loop.apng` 作为
  Web/其他平台的等价交付物，若要在 Qt 用需自行集成 APNG 解码。
- 绘制顺序：静态底板（含 AI）→ 光环当前帧 → 进度条 → 文字 → 品牌区。
- 光环层为 **560×560 正方形透明贴层**，按 **1:1 原尺寸**贴在
  (232, 16)，**不做任何缩放**，因此不存在 4:3 拉伸变形。
- **AI 标识的两种接法**：默认直接用 `loading_bg@1024.png`（已含 AI，最省一次绘制）；
  若希望 AI 由代码控制/着色/隐藏，改用 `loading_bg@1024_no_ai.png` +
  `ai_mark.png`（220×140 透明，贴到 (402, 226)，1:1 不缩放）。
  两者像素结果完全一致，**不要同时叠加**，否则 AI 会重影。

## 5. 动画参数与无缝循环

| 项 | 值 |
|---|---|
| 光环层尺寸 | 560×560 RGBA（真透明 PNG-24 + alpha） |
| 帧数 | **40** |
| 单帧时长 | **75 ms** |
| 单次循环 | **3000 ms = 3.0 s** |
| 帧率 | **13.33 fps**（≤ 20fps） |
| 循环方式 | `loop=0` 无限循环；PNG 序列由 QTimer 控制，播放到 39 帧后回 0 |

**无缝校验**：所有旋转量在一个循环内为整数圈（虚线环 +1 / -1 / +2 圈，
亮弧 +1 / -2 / +3 圈，外圈刻度点 +1 圈），呼吸项为 `sin(2πt)`。
生成脚本额外渲染 `t=1` 帧与 `t=0` 帧逐像素比较：
**平均差 0.0000、最大差 0**，即首尾完全衔接，无跳帧、无闪烁。

**辉光处理**：动态层只含清晰线条，柔光一次性画入静态底板
（避免每帧大面积低 alpha 噪声，体积与解码开销都更低）。

## 6. 6 段语义与状态机

| # | 阶段 | 段中心 x |
|---:|---|---:|
| 1 | 配置读取 | 242 |
| 2 | 方案与相机 | 350 |
| 3 | 串口与机型 | 458 |
| 4 | AI 参数下发 | 566 |
| 5 | 界面与数据 | 674 |
| 6 | 设备自检 | 782 |

- 进行中：该段 `active`（青），其余未完成段 `idle`。
- 完成：该段 `ok`（绿）并推进下一段。
- 失败：该段 `error`（红）+ 显示失败提示行，**后续段保持 idle**，一眼看出卡在哪一段。
- 中央文字显示当前阶段名；失败时改为「XX 失败」并给出失败项。

## 8. 关于 6 个阶段图标

`icon_config / icon_scheme / icon_serial / icon_ai / icon_ui / icon_check.svg`
均为 24×24、`stroke="currentColor"` 的单色线性图标，Qt 端用 `QSvgRenderer`
配合 `QColor` 着色即可。当前启动版式未预留图标位（安全区与文字/进度条已排满），
建议用于**启动完成后的自检列表面板**；若必须在启动画面显示，
可将进度条整体下移 32px，图标置于每段中心 x、y=620。
